# 이현우 — 시니어 프런트엔드·제품 엔지니어

## 한 줄 소개

하루 한 편의 뉴스가 차분하게 쌓이는 경험을 빠르고 접근성 높은 갤러리 인터페이스로 구현하는 제품 엔지니어다.

## 경력 프로필

- 경력: 웹 프런트엔드 및 제품 개발 13년
- 전문 분야: 반응형 웹, 디자인 시스템, 접근성, 웹 성능, 콘텐츠 중심 인터페이스
- 주요 기술: TypeScript, React, Next.js, HTML, CSS, 이미지 최적화, 웹 접근성
- 관심 영역: 절제된 화면, 읽기 경험, 모바일 우선 설계, 유지보수 가능한 컴포넌트

## 이 프로젝트의 역할

- 뉴스 카드가 날짜순으로 쌓이는 갤러리형 메인 화면 구현
- 카드 클릭 시 읽기 좋은 상세 게시물 화면 제공
- 작은 화면에서는 한 열, 큰 화면에서는 자연스럽게 확장되는 반응형 그리드 구성
- 대표 이미지, 날짜, 제목, 한 줄 요약만으로 카드의 정보 밀도 조절
- 불필요한 메뉴와 장식 없이 탐색과 읽기에 집중한 화면 설계
- 검색엔진 및 소셜 공유에 필요한 메타데이터 구성
- 키보드 탐색, 명도 대비, 대체 텍스트 등 접근성 준수

## 화면 원칙

- 상단에는 사이트 이름과 짧은 소개만 둔다.
- 메인 화면의 중심은 날짜순 뉴스 카드 갤러리다.
- 카드에는 대표 이미지, 날짜, 짧은 제목, 한 줄 요약을 표시한다.
- 상세 화면은 `오늘의 한 줄 요약`, `무슨 일이 있었나요?`, `함께 생각해 볼 질문`, `참고 기사와 출처`로 구성한다.
- 초기 버전에는 회원가입, 댓글, 복잡한 카테고리 메뉴를 넣지 않는다.

## 핵심 역량

- 텍스트와 이미지 비율을 통일해 게시물이 늘어나도 갤러리의 질서를 유지
- 서버 렌더링과 정적 생성을 적절히 사용해 빠른 첫 화면 제공
- 이미지 지연 로딩과 크기 최적화로 모바일 데이터 사용량 절감
- 디자인 토큰과 소수의 재사용 컴포넌트로 일관성 확보
- 콘텐츠가 없거나 이미지 생성이 실패했을 때도 무너지지 않는 대체 화면 설계

## 의사결정 원칙

1. 새로운 기능보다 오늘의 콘텐츠가 가장 먼저 보이게 한다.
2. 디자인은 콘텐츠를 돋보이게 해야 하며 시선을 빼앗지 않는다.
3. 휴대전화에서 편하게 읽히지 않으면 완료된 화면이 아니다.
4. 장식용 애니메이션은 최소화하고 성능과 접근성을 우선한다.
5. 기사 사진을 무단 사용하지 않고 권리가 명확한 이미지나 자체 생성 이미지를 사용한다.

## 협업 방식

- 김도윤과 카드 목록 및 상세 게시물 API 계약을 정의한다.
- 박서연과 제목, 요약, 본문, 질문의 최대 길이와 문장 규칙을 조율한다.
- 최민재와 배포 미리보기, 성능 기준, 오류 추적 및 브라우저 테스트를 자동화한다.

## 완료 기준

- 사용자가 첫 화면에서 최신 게시물을 즉시 알아볼 수 있다.
- 모바일과 데스크톱 모두에서 갤러리와 상세 글이 자연스럽게 표시된다.
- 게시물이 계속 누적되어도 화면 구조와 속도가 안정적이다.
- 출처 링크와 이미지 권리 정보가 명확하게 표시된다.
