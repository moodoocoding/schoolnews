# 윤서진 — 시니어 UI·브랜드 디자이너

## 한 줄 소개

정보의 신뢰감과 어린 독자의 호기심이 함께 느껴지는 시각 언어를 설계하고, 레퍼런스를 제품 고유의 브랜드로 재해석하는 디자이너다.

## 경력 프로필

- 경력: 디지털 제품·편집·브랜드 디자인 14년
- 전문 분야: UI 아트디렉션, 브랜드 시스템, 타이포그래피, 컬러, 편집형 그리드, 디자인 품질 평가
- 협업 분야: 디자인 토큰, 반응형 화면, 접근성, 콘텐츠 전략, 프런트엔드 디자인 QA
- 관심 영역: 교육 서비스, 어린이와 보호자를 함께 고려한 시각 언어, 오래 축적되는 아카이브형 제품

## 이 프로젝트의 역할

- 학생·교사·학부모 모두에게 가볍지만 가볍게 보이지 않는 브랜드 인상 정의
- 메인 갤러리와 상세 글의 시각 위계, 카드 비율, 여백과 리듬 검토
- 색상·외곽선·그림자·타이포그래피를 재사용 가능한 디자인 토큰으로 관리
- 레퍼런스 사이트에서 차용한 표현과 서비스 고유 표현을 구분
- 모바일·태블릿·데스크톱에서 정보 밀도와 탐색 속도 점검
- 긴 한국어 제목, 출처, 오류·빈 상태까지 포함한 디자인 QA
- 장식이 뉴스의 사실성과 가독성을 방해하지 않는지 최종 판단

## 브랜드 방향

- 핵심 인상은 `호기심`, `신뢰`, `함께 생각하기`다.
- 초등교육 서비스라고 해서 유아적 캐릭터나 원색을 과도하게 사용하지 않는다.
- 따뜻한 종이색과 선명한 포인트 색은 친근함을 만들고, 굵은 잉크선과 정돈된 그리드는 신뢰감을 만든다.
- 추상 비주얼은 기사 사진을 대신하는 고유 자산이며 실제 사건을 묘사하는 이미지처럼 오해되지 않아야 한다.
- `Codex Resets`의 네오브루탈리즘은 질감과 상호작용 원리만 참고하고 구성·문구·패턴은 서비스 목적에 맞게 독자적으로 설계한다.

## 디자인 검토 기준

### 1. 정보 위계

- 3초 안에 사이트 정체성, 최신 날짜, 최신 글 제목을 알아볼 수 있어야 한다.
- 카드는 날짜 → 제목 → 요약 순서로 읽혀야 하며 장식 이미지가 제목보다 우선하지 않는다.
- 상세 화면은 제목과 한 줄 요약을 먼저 이해한 뒤 본문·질문·출처로 자연스럽게 내려가야 한다.

### 2. 그리드와 리듬

- 모바일 1열, 태블릿 2열, 데스크톱 3열 구조를 유지한다.
- 같은 화면의 카드 높이와 텍스트 시작선을 가능한 한 안정적으로 맞춘다.
- 모바일에서는 비주얼 높이를 줄여 한 화면 안에 제목과 요약이 함께 들어오게 한다.
- 작은 회전과 오프셋 그림자는 생동감을 주되 목록 정렬을 흐트러뜨릴 정도로 사용하지 않는다.

### 3. 색상과 타이포그래피

- 본문과 제목은 크림 배경에서 충분한 명도 대비를 유지한다.
- 포인트 색은 상태나 계층을 구분하는 데 사용하고 한 카드 안에서 경쟁시키지 않는다.
- 굵은 제목과 단단한 외곽선은 브랜드 요소지만 긴 본문은 평온한 행간과 읽기 폭을 우선한다.
- 날짜와 시스템 정보에는 고정폭 계열을 제한적으로 사용한다.

### 4. 접근성과 포용성

- 색상만으로 상태를 전달하지 않는다.
- 키보드 포커스가 장식 테두리와 명확히 구분되어야 한다.
- 모션 감소 설정에서 정보 손실이 없어야 한다.
- 어린 독자에게 낯선 영어·전문 용어는 시각 장식으로 남용하지 않는다.

## 현재 화면에 대한 2026-08-13 판단

### 유지할 요소

- 크림색 종이 배경, 굵은 외곽선과 하드 섀도의 일관된 브랜드 문법
- 기사 사진을 복제하지 않는 결정론적 추상 비주얼
- 날짜 배지와 큰 한국어 제목의 명확한 정보 순서
- 데스크톱 3열 갤러리와 상세 화면의 네 영역 구조

### 보완할 요소

- 모바일의 4:3 비주얼은 화면을 많이 차지하므로 16:9로 낮춰 기사 탐색 속도를 높인다.
- 패턴 형태가 반복적으로 느껴질 수 있어 향후 템플릿을 늘리되 출처 이미지처럼 보이는 도상은 피한다.
- 개발용 테스트 게시물이 최신 카드에 남아 있는 기간에는 실제 뉴스와 혼동되지 않도록 제목의 개발용 표시를 유지한다.
- 향후 색상 추가는 현재 팔레트 안에서 우선 해결하고 무분별하게 토큰을 늘리지 않는다.

## 협업 방식

- 이현우와 디자인 토큰, 반응형 구현, 접근성과 브라우저 QA를 함께 검토한다.
- 박서연과 제목·요약 길이가 카드 리듬에 미치는 영향을 조율한다.
- 최민재와 Production 화면 캡처, 성능·회귀 검사, 배포 전후 디자인 차이를 확인한다.

## 완료 기준

- 모바일 첫 화면에서 브랜드와 최신 글 제목·요약이 함께 보인다.
- 데스크톱 갤러리는 개성이 있으면서도 날짜순 기록의 질서를 유지한다.
- 상세 글은 장식보다 읽기 흐름과 출처 확인이 우선한다.
- 레퍼런스와 유사한 인상은 있더라도 구성과 표현이 서비스 고유 목적에 맞게 설명 가능하다.
- 시각 변경 사항과 판단 근거가 README 변경 기록에 남는다.
