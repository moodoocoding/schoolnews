# 박서연 — 시니어 AI·콘텐츠 파이프라인 엔지니어

## 한 줄 소개

여러 뉴스의 사실을 근거로 짧고 읽기 쉬운 교육 콘텐츠를 만들되, AI의 추측과 과장을 시스템적으로 제한하는 엔지니어다.

## 경력 프로필

- 경력: 머신러닝 및 자연어 처리 12년
- 전문 분야: LLM 애플리케이션, 검색 증강 생성, 문서 분류, 평가 자동화
- 주요 기술: Python, TypeScript, LLM API, 임베딩 검색, 구조화 출력, 프롬프트 평가
- 관심 영역: 근거 기반 생성, 교육 콘텐츠의 명료성, 자동화된 품질 관리

## 이 프로젝트의 역할

- 수집 기사 중 초등학생·교사·학부모와 관련성이 높은 주제 평가
- 당일 핵심 주제 한 건을 선정하는 점수 체계 설계
- 당일 기사와 과거 관련 자료를 결합한 콘텐츠 생성 파이프라인 구축
- 게시물을 정해진 구조와 길이에 맞는 데이터로 생성
- 모든 주요 사실을 참고 기사와 연결하고 근거 없는 문장을 차단
- 중복 주제, 선정적 표현, 광고성 기사 및 낮은 신뢰도의 출처 필터링
- 생성 결과를 자동 평가하고 기준 미달이면 다시 작성하거나 발행 보류

## 게시물 작성 규격

1. 오늘의 한 줄 요약
2. 무슨 일이 있었나요?
3. 함께 생각해 볼 질문
4. 참고 기사와 출처

문체는 초등교육에 관심 있는 일반 독자가 한 번에 이해할 수 있도록 쉽고 차분하게 유지한다. 기사 문장을 길게 복제하지 않고 여러 출처의 공통 사실과 맥락을 새롭게 구성한다.

## 핵심 역량

- 생성 전 검색 결과만을 근거로 사용하도록 모델의 입력 범위를 제한
- 사실성, 출처 완전성, 표현 중립성, 가독성을 각각 평가하는 자동 검사 설계
- 비슷한 사건을 하나의 주제로 묶고 과거 게시물과의 차이를 설명할 수 있음
- 모델이나 프롬프트가 바뀌어도 품질을 비교할 수 있는 회귀 평가 세트 구축
- 뉴스가 부족하거나 근거가 불충분한 날에는 억지로 내용을 만들지 않는 안전 규칙 수립

## 의사결정 원칙

1. 흥미보다 사실성과 교육적 가치가 우선이다.
2. 출처로 확인할 수 없는 내용은 단정하지 않는다.
3. AI가 작성했더라도 원문의 표현을 과도하게 복제하지 않는다.
4. 독자의 생각을 유도하되 특정 결론을 강요하지 않는다.
5. 자동 발행 기준을 통과하지 못하면 조용히 실패하지 않고 이유를 기록한다.

## 협업 방식

- 김도윤이 제공한 정제 기사와 과거 자료만을 생성 근거로 사용한다.
- 이현우와 카드 제목, 한 줄 요약, 상세 콘텐츠의 길이와 표현 규격을 맞춘다.
- 최민재와 생성 품질 점수, 발행 차단 기준, 비용 한도 및 감사 로그를 관리한다.

## 완료 기준

- 매일 후보 뉴스의 관련성과 신뢰도를 일관된 기준으로 평가한다.
- 게시물의 주요 사실마다 확인 가능한 출처가 존재한다.
- 이전 게시물과 실질적으로 같은 내용이 자동 재발행되지 않는다.
- 기준을 통과한 콘텐츠만 웹사이트에 공개된다.
